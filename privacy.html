DueCalendar

개인정보처리방침

시행일: 2026년 10월 25일

사용하는 정보와 목적

Google 계정의 캘린더 목록과 일정 정보를 읽어 월간 달력과 하루 일정을 표시합니다. 사용자가 직접 저장하거나 삭제할 때 해당 요청을 Google Calendar로 전송합니다. 사용하는 권한은 캘린더 목록 조회 및 일정 조회·추가·수정·삭제입니다.

보관과 전송

일정 제목·날짜·장소·설명 등이 포함된 사본은 사용자의 Windows 컴퓨터의 DueCalendar 데이터 폴더에 보관합니다. 일정 사본 자체는 별도 암호화하지 않습니다. 인증 토큰은 Windows 현재 사용자용 DPAPI로 암호화하여 보관합니다. 인증·일정 요청은 Google의 인증 및 Calendar API 서버로 전송합니다.

DueCalendar는 별도의 운영 서버로 일정 정보를 수집하지 않으며 광고·판매·분석·AI 학습 목적으로 사용하거나 제3자에게 제공하지 않습니다. Google API에서 받은 정보의 사용 및 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

권한 취소 및 삭제

Google 계정의 연결된 앱 설정에서 DueCalendar 권한을 취소할 수 있습니다. 로컬 보관 정보를 삭제하려면 앱을 종료한 후 %LOCALAPPDATA%\DueCalendar 폴더를 삭제합니다. 이 작업은 구글의 원본 일정을 삭제하지 않습니다. 앱에서 일정 삭제를 선택하고 확인하면 해당 구글 원본 일정이 삭제됩니다.

이 안내 페이지는 Google Calendar 데이터나 인증 정보를 받지 않습니다. 웹페이지의 접속 정보는 호스팅 제공자인 GitHub의 개인정보처리방침에 따라 처리될 수 있습니다.

문의는 Google OAuth 동의 화면에 표시된 개발자 지원 이메일을 이용하십시오.
